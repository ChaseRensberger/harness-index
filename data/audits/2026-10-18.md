# October 18, 2026 catalog audit

Six agents researched all 184 original entries against project sources and rewrote their descriptions.
The review covered names, links, categories, interfaces, source classifications, licenses, implementation languages, stars, status, and provenance.
The final catalog contains 178 entries after seven removals and one product split.

[Research records](2026-10-18.json) preserve the sources, findings, and unresolved questions for every original entry.
Those records precede the decisions below. An agent's `verified` outcome means its reviewed claims had supporting sources, not that the software passed runtime tests.
The review did not install or execute every project. Star counts and availability remain dated observations.

## Removed entries

Four entries lack enough evidence for a permitted source classification:

- `claw-code-agent`: [The repository](https://github.com/HarnessLab/claw-code-agent) provides code but no explicit license grant in its README, package metadata, or license files.
- `free-code`: [The README](https://github.com/freecodexyz/free-code#license) identifies exposed proprietary source without a license grant from its owner.
- `fetchcoder`: [Official documentation](https://innovationlab.fetch.ai/resources/docs/fetchcoder/overview) labels the product MIT. The inspected package contains an installer, and the runtime source and license scope remain unresolved.
- `metr-triframe-inspect`: [The repository](https://github.com/METR/triframe_inspect) implements an agent, but its README, package metadata, and tree provide no project license.

Three entries do not establish qualifying execution infrastructure:

- `live-swe-agent`: [The project](https://github.com/OpenAutoCoder/live-swe-agent) supplies prompting and configuration for mini-SWE-agent rather than a separate runtime or execution infrastructure.
- `mentat-cli`: [The current npm package](https://registry.npmjs.org/@abanteai/mentat/latest) controls remote agents. The imported entry did not identify whether it meant this client or the distinct archived Python agent.
- `smol-developer`: [The implementation](https://github.com/smol-ai/developer) follows fixed planning and file-generation steps with user-supplied feedback. It does not establish an adaptive tool loop or substantial execution infrastructure.

Removal reflects insufficient classification or inclusion evidence. A failed fetch alone does not establish that a project is unavailable.
Historical projects remain eligible when their identity and infrastructure are established. ChatGPT agent therefore remains listed as discontinued.

## Product identity and license decisions

Perplexity Computer and Comet are separate products, so each now has its own description and terms link.
Computer keeps the original `perplexity-computer-comet` ID to preserve existing links. Comet uses `perplexity-comet`.
Evidence includes the [Computer announcement](https://www.perplexity.ai/hub/blog/introducing-perplexity-computer), [access documentation](https://www.perplexity.ai/hub/workshops/introducing-perplexity-computer), and [Comet use cases](https://comet-help.perplexity.ai/en/articles/11732243-advice-and-use-cases).
Some Perplexity pages blocked direct retrieval. The review used indexed official content and does not imply direct retrieval of every page.

Coro Code explicitly declares MIT OR Apache-2.0 in its README and package metadata, although the linked license files are missing.
It remains open source on that declared basis. Its license label records the missing files, and its evidence link points to the actual declaration.
Claude Engineer, claw0, and g3 also declare MIT without complete license files. Their declarations support classification, but full license text remains missing.
Snow CLI supplies incomplete Apache-2.0 text. VT Code supplies Apache-2.0 text while its README and package metadata also claim an MIT alternative.
VT Code's entry records the inspected Apache option. These findings do not resolve upstream documentation defects.

Mastra and Dyad combine open-source core code with restricted enterprise code. Their source-available classification covers the combined repository.
Stagewise combines AGPL code with restricted icon assets. Its license label identifies that distinction.
The Python Claude Agent SDK and Antigravity SDK are open-source wrappers that require proprietary runtime components.
Their descriptions state that boundary. The SDK license does not establish the runtime's license.

## Remaining uncertainty

Closed products often do not disclose their implementation languages. Those fields remain `Unknown`, and support-repository languages do not substitute for runtime evidence.
Some dormant statuses reflect observed inactivity rather than an explicit maintainer announcement.
AutoGen's top README declares archival while its repository flag and older README text disagree. The entry follows the explicit support notice.
ChatGPT agent's help page also retains older availability text below its discontinuation notice. The entry follows the discontinuation notice.

Separately named products can share execution code. Devin Desktop and Devin CLI share their local runtime, as their descriptions explain.
Shared-repository star counts are not additive. No count is a measure of product usage, quality, or reliability.
The research records preserve entry-specific limitations and source failures for future reviews.
